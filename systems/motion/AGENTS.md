# Motion: system rules

Motion is the **reference system** of KrackedUI: calm, content-first, dense. It implements the full
contract plus two modules (block **editor**, **database** views). Root rules: `/AGENTS.md`;
the standard: `/standard/SPEC.md`. These rules add Motion's specifics.

## Where things go
```
registry/src/
  foundations/   Theme, layout primitives (Stack, Grid)
  icons/         Icon + generated paths (systems/motion/tooling/icon-map.json → npm run icons:motion)
  atoms/         Button, IconButton, Badge, Tag, Avatar, Kbd, Divider, Spinner, Tooltip, Link, inputs…
  forms/         Field, Select, Combobox, NumberInput, Slider, Calendar, DatePicker, DateRangePicker, FileUpload
  components/    Menu, ContextMenu, Popover, Dialog, Sheet, Toast, Tabs, SegmentedControl, CommandPalette, Breadcrumbs…
  data/          Card, Stat, Table, DataTable, Pagination, EmptyState, Skeleton, Progress, Accordion, Alert
  charts/        LineChart, BarChart, DonutChart, Sparkline
  shell/         AppFrame, Sidebar, Topbar, PageHeader, peeks, settings
  blocks/, editor/   module: block editor
  database/      module: database views
  lib/           cn, tv, shared hooks (no components)
  styles/        tokens.css (generated), theme.css, standard.css (--ds-* mapping), motion.css (animations)
registry/test/   behaviour tests for Motion extras and modules (contract tests live in /standard/gate/tests)
docs/            registry.tsx (nav + pages), pages/<group>.tsx, foundations.tsx, theme.css, chrome.tsx
templates/       project-management/, fintech/
playground/      lab pages at #/lab/<group> (internal)
```
One folder owns each group; its `index.ts` re-exports the group. `src/index.ts` only re-exports groups.

## Tokens
- Motion tokens are `--n-*` CSS variables and Tailwind utilities (`bg-n-bg-primary`, `text-n-text-secondary`,
  `border-n-border-primary`, `shadow-n-shadow-outline-md`, `rounded-n-{xs,sm,md,lg,xl,2xl,3xl}`,
  `text-n-{h1,h2,h3,body,ui,ui-medium,ui-sm,caption,code,page-title}`). `-a` = translucent.
- Named palette: gray, brown, orange, yellow, green, blue, purple, pink, red, teal, each with
  text-/bg-/icon-/border- primary/secondary/tertiary/accent-primary (e.g. `bg-n-red-bg-secondary`).
- `--ds-*` (the standard vocabulary) is mapped in `styles/standard.css`. Prefer `--n-*` inside Motion,
  `--ds-*` in anything meant to be portable.
- No hard-coded colors. A measured value with no token: arbitrary value + `/* token-exempt: reason */`.
- Contract `tone` → Motion color: neutral=gray, accent=blue, success=green, warning=yellow/orange, danger=red, info=blue.
- Contrast: secondary/tertiary greys are tuned to meet WCAG AA (4.5:1). Do not lighten them back.

## Look and feel
Quiet surfaces, hairline borders, small radii (4–8 px), 14 px UI text, hover = translucent grey wash,
one accent (blue) for primary actions and focus. Dense by default; touch targets grow to 24 px+
under `(pointer: coarse)`. When adding a component, match the closest existing one before inventing.

## Conventions
- `tv()` recipes exported as `xVariants`; `forwardRef` leaves; `cn` merge; spread rest props.
- Compound = `export const X = { Root, … }`; flat aliases are generated by the build.
- Radix primitives from `radix-ui` for overlays, menus, selects, sliders, accordions, tabs.
- Animations live in `styles/motion.css` and use `--ds-motion-*`; respect reduced motion.
- JSDoc each component: what it is, when to use it.

## Verifying a change (before you call it done)
1. Lab: add/adjust the component on `playground/src/lab/pages/<group>.tsx`; check light, `?dark`,
   and a 375 px wide window.
2. `npm run gate -- motion --only typecheck,lint,tokens,contract,tests`
3. Docs page updated (examples, API table, accessibility, usage); `npm run gate -- motion --only docs`.
4. For visual or layout changes: `--only a11y,responsive`.

## Reference material (private)
Measurements this system was derived from are kept outside the public repository (`capture/`,
`mirror/`, private tooling). Never copy assets or names from them into the package, docs or templates.
