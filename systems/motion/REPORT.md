# Motion: report

Motion is the KrackedUI reference system. This report tracks what the gate measured, what the
templates found, and decisions taken. Gate results: `GATE.md` (written by `npm run gate -- motion`).

## Package (@krackedui/motion)

- Build: `npm run build:motion` → `dist/`: `index.js` (entry), `client.js` ("use client": components),
  `server-safe.js` (pure helpers), `index.d.ts`, `styles.css` (precompiled: tokens + utilities + scoped reset;
  no Tailwind needed), `tailwind.css` (tokens as utilities for Tailwind v4 apps), `tokens.json`.
- Release check: `npm run test:package` packs the tarball and builds fresh consumer apps (Vite without
  Tailwind, Next.js App Router server page, README example). Passing as of 2026-10-15.
- Compatibility notes: compound parts have flat aliases (`MenuRoot`, `SidebarItem`…, 53 total) for React
  Server Components; portaled layers (menus, popovers, dialogs, editor menus) follow a dark `.motion-root`.
- `private: true` in package.json until a private registry is chosen (prevents accidental public publish).
